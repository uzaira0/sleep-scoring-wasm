# Security reporting

For a suspected vulnerability in the current published PWA, use
[GitHub private vulnerability reporting](https://github.com/uzaira0/sleep-scoring-wasm/security/advisories/new)
(**Security → Advisories → Report a vulnerability**). Reports go privately to the solo maintainer, uzaira0.
Do not file vulnerability details as a public issue.

Include the browser/version, build or bundle ID, impact, and minimal steps using the built-in
synthetic demo or generated data. Never attach participant recordings, diaries, identifiers or exports.

There is no guaranteed response time. The current deployed build is the supported release;
fixes are delivered through the operator's gated ship process.

Private reporting must be enabled by the repository owner. If GitHub does not offer the private
report form, do not post the vulnerability publicly; wait for the owner to enable this route.
